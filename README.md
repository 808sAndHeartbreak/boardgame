# 桌游身份发放工具

狼人杀类桌游身份发牌网页版工具，供团建与线下桌游主持人使用。竖屏手机优先，支持随机发牌、逐人展示、身份调配、夜间流程、出局恢复与笔记。

[在线使用](https://boardgame.run.ingarena.net/) · [上线检查](docs/release-check.md) · [部署说明](docs/deployment.md)

## 玩法

- **标准狼**：默认 12 人，4 民、4 狼、预言家、女巫、猎人、白痴，可编辑人数、角色与技能。
- **双身份**：5–8 人预设，每人两张，至少一位双民金宝宝。默认一个隐狼，7 人预设另含白狼王；隐狼默认在下，金刚狼默认可完杀一次。可切换预言家与狼牌不同手的限制。
- **自信狼**：默认 9 人，3 民、3 狼、预女猎；看下家底牌，跳过开局夜，第一天两轮发言后放逐，无警长。仅此模式记录睁错眼暴毙。
- 阿瓦隆暂未开放。

## 使用

1. 选择模式，配置牌库和桌规，生成身份。
2. 主持人可交换任意两张牌进行调配；逐位展示是可选操作，未展示完也可确认开局。
3. 开局后在「流程」记录行动，在「玩家」查看身份、切换在场状态与保存玩家笔记。
4. 「笔记」直接显示全部阶段记录及身份、玩家笔记；「阶段」可回看历史。

行动目标与实际倒牌分开记录，守护、连锁技能和胜负由主持人确认。倒牌、恢复均需确认；恢复会撤回相关倒牌及后续关联记录。

**数据保存在当前浏览器的本地存储中**，不上传身份或笔记，不跨设备同步。重新发牌会替换当前一局。清理浏览器数据会清除记录。离线文件和线上网站的浏览器存储相互独立。

## 本地运行

需要 Node.js 20 或更新版本，无第三方运行依赖。

```sh
npm run build
npm test
npm start
```

打开 `http://localhost:3000`。可通过 `PORT`、`HOST` 环境变量调整监听地址。部署默认监听 `0.0.0.0:3000`，健康检查为 `/healthz`。

仓库附带可直接打开的 `offline.html`。从源码重建离线文件：

```sh
node scripts/build.cjs --offline
```

## 目录

```text
src/               页面、规则核心、交互与样式源文件
public/            在线站点与 WebP 插画资源
scripts/build.cjs  在线/离线构建
server.cjs         静态服务、Gzip、缓存与健康检查
tests/             规则回归检查
docs/              使用预览与上线检查记录
offline.html       单文件离线版
```

视觉沿用黑白暖纸、朋克红点缀、剪纸拼贴与限色印刷，插画为生成素材。支持减少动态效果；使用系统字体，无远程字体、分析脚本或 CDN 依赖。
